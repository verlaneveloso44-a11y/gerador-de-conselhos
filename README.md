# Gerador de Conselhos (Advice Generator)

Uma aplicação web interativa e responsiva que consome uma API pública para gerar conselhos aleatórios, com **tradução automática para o português** e **botões integrados para compartilhamento nas redes sociais**.

---

##  Demonstração

🔗 [Acesse o projeto online](https://verlaneveloso44-a11y.github.io/gerador-de-conselhos/)

---

##  Funcionalidades

* **Conselhos Aleatórios:** Busca frases da *Advice Slip API* sem repetição por cache.
* **Tradução Automática:** Traduz os conselhos de inglês para português em tempo real utilizando a *MyMemory Translation API*.
* **Cópia Rápida:** Botão para copiar o texto direto para a área de transferência.
* **Compartilhamento Social:**
* **WhatsApp:** Abre o aplicativo com o texto formatado para enviar no Status ou conversas.
* **Facebook:** Compartilhamento direto via janela da plataforma.
* **Instagram:** Copia o texto automaticamente e redireciona para a rede.
* **Twitter / X:** Cria um tweet pronto com a frase e hashtag.


* **Layout Responsivo:** Design moderno ajustável para dispositivos móveis e desktop.

---

## Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização com Flexbox, gradientes e variáveis visuais.
* **JavaScript (ES6+):** Consumo de APIs assíncronas via `fetch`, manipulação do DOM e uso da API `navigator.clipboard`.
* **APIs Externas:**
* [Advice Slip API](https://api.adviceslip.com/)
* [MyMemory Translation API](https://mymemory.translated.net/)
